n8n Course — Workflow Pack

Import kaise karein:
1. n8n kholo → naya workflow
2. .json file ka poora content copy karo → canvas par Ctrl+V (Mac: Cmd+V)
   YA: ... menu → Import from File
3. Har workflow ke "Setup Note" (peela sticky) mein likhe credentials connect karo
4. Test workflow → sab green → Active
